Exhibit 01

AI Navigation Glasses

The enclosure shown on the homepage is Continuous Facets v0.4, the editable model in that release note, not a photograph of a manufactured device. Below a 0.70 confidence threshold the guidance engine says “uncertain” instead of issuing a command. That default is in the project README. The work credits the upstream framework AI-FanGe / OpenAIglasses_for_Navigation.

The participant survey, with the raw CSV, is published in docs/FEEDBACK.md and the response CSV: 85 responses; of 64 people who had used the glasses, 9 of 64 were still using them; 31/64 (48%) reported inaccurate prompts.

The mean helpfulness score in the same document is 3.47 out of 5. The survey’s method table also records that 51 of the 85 responses were not filled in directly by the respondent: 34 were entered by a family member or volunteer, 14 by an activity organiser, and 3 another way. The glasses project page publishes that disclosure beside the headline figures.

The project page also publishes the Bosch evaluation (docs/EVALUATION.md): on 61 single-state red/green frames the laptop camera path committed to a state on 4 frames (coverage 6.6%); 1 red frame was read as green; and on 104 frames containing no annotated light it emitted green on 2. The document states this is a distant, vehicle-camera benchmark, not head-worn near-field performance, and that the dataset images are not redistributed. The synthetic harness (docs/EVAL.md) records 0 false prompts and 0 misses on 14 drawn frames in 11 clips — drawn lamp discs, not street validation.

Exhibit 02

GERT v1.4 was not promoted

The homepage says version 1.4 missed its pre-set Q90, Q95, and Q99 calibration thresholds and was not promoted. The machine-readable evaluation gives the absolute coverage errors: Q90 0.035417, Q95 0.04375, and Q99 0.031667, each against the predeclared gate of absolute error <= 0.03. The same file is the evidence cited by the decision record in the dataset archive, DOI 10.5281/zenodo.22975251.

The public Historical Lab uses 216 hours of ERCOT native-load observations. That count is the dataset title and description at DOI 10.5281/zenodo.22975251. The lab itself is gert-d.vercel.app, and the project site named on the homepage is gertgrid.space.

The project page also quotes the Historical Lab summer-2023 case from the repository README (README table): at an assumed capacity of 80,000 MW, observed load exceeds capacity for 21 hours (66,683 MWh unserved-energy proxy); with a 5% load reduction, 7 hours (4,458 MWh). The capacity is a stated assumption, not a measurement. The same decision record gives the Q50 coverage error as 0.0208 (passed), which the project page’s gate chart rounds to 0.021.

The homepage’s “141 backend and 50 frontend tests, run 2026-11-09” is the suite at commit 796e7683c5 (2026-11-05), which was still the tree on 2026-11-09. The public run of that tree is Actions run 42078031209. Counted from the test files at that commit: 141 backend tests and 50 frontend tests.

Updated count: the tool site’s footer, read 2026-11-17, states “Automated tests passing on 2026-11-17: 142 backend and 51 frontend”. The homepage’s Tests line now uses this dated count; the 2026-11-09 count above stays as the earlier record.

The decision record adds that v1.4 showed pinball skill of 0.76 to 0.84 across quantiles against the frozen seasonal baseline, and was rejected anyway: the calibration gate, not the skill score, is the promotion decision. The evaluation window was frozen at 96 hours (2026-08-21 to 2026-08-24) before it was opened.

Two pilots are recorded in docs/FEEDBACK.md: Session 1 in May 2026 and Session 2 on 2026-09-08. The participant figures in that document are marked organiser-reported and unverified, with no raw responses, so no participant count is published here or on the project page. The public count record is the tool’s community ledger (updated 2026-09-25): 4 organiser-forwarded reports, 2 hands-on core completions, 0 independent retests.

Software archive: DOI 10.5281/zenodo.23982226. Dataset archive: DOI 10.5281/zenodo.22975251.
